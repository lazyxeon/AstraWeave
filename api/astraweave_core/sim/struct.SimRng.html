Struct SimRng

pub struct SimRng { /* private fields */ }
Expand description

Simulation RNG. One stream per (world_seed, tick, system_id).

Draws are StdRng (ChaCha12). Reseed from SimRng::new at the start of a tick so the sequence does not depend on how many values the previous tick consumed. Float draws that must be bit-identical across platforms should use SimRng::unit_f32, which is a dyadic rational, not libm.

pub fn unit_f32(&mut self) -> f32

f32 in [0, 1) from the top 24 bits. Every value is a multiple of 2^-24, so the bit pattern does not depend on libm or on rand’s float distribution.
