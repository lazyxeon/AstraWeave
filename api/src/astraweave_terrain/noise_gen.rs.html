71    /// gradient is large, producing smoother output on steep slopes where
72    /// spikes would otherwise accumulate. Does NOT disable the domain-warp
73    /// coordinate displacement — that still runs before the derivative-
74    /// weighted fBm primary sample. Default false (preserves F.2-T-3

81    /// to subsequent octaves to break the "first octave dominates" pattern
82    /// that produces uniform peak shapes.
83    ///
84    /// `None` = use standard `persistence^i` exponential decay (Quilez H=1

89    /// Slice length should equal or exceed `base_elevation.octaves`.
90    ///
91    /// Only applies when `base_derivative_weighted` is also true (the
92    /// derivative-weighted path is the only one with explicit per-octave
93    /// loop access; non-derivative paths use opaque `noise` crate Fbm).
94    ///
95    /// Bespoke tuning — no published source provides specific numerical
96    /// weights for "Uber Noise". F.4.B.3.A research surveyed Quilez,
97    /// Musgrave, ithy.com, and primary-source-proxy of Murray's GDC talk;
98    /// none provide reference curves. Tuning is empirical via Andrew-gate.

101    /// Phase 1.6-F.4.B.3.B (infrastructure-only): per-octave amplitude

103    /// mountain layer uses `Box<dyn NoiseFn>` (`RidgedMulti` or `Fbm` from
104    /// the `noise` crate) which does its octave summation internally with
105    /// no per-octave hook. F.4.B.3.B sets up this field for forward
106    /// compatibility with a future sub-phase (likely F.4.B.3.E or
107    /// follow-up) that replaces the mountain layer with a custom multi-
108    /// octave evaluator supporting per-octave weights. Until then this

111    ///
112    /// Documented separately in §10 F.4.B.3.B entry as scope-deferral.

141fn default_continental_enabled() -> bool {
142    // E3-terrain.3 (2026-07-01): flipped false → true. Continental clustering
143    // was built + tuned by Phase 1.6-F.2/F.2-T to gate the mountain layer into
144    // regional highland/lowland zones (fixing the "bed-of-nails / all-mountains,
145    // no lowlands" surface), but the path that enabled it (F.2.B presets) was
146    // removed in F.4.B.3.D.3c and never re-homed, so it shipped off. Every
147    // F.2-T regression test already forces it true — the tuning assumed ON.
148    // Enabling it drops the default world's median ~190m → ~125m with regional
149    // peaks retained, so climate/archetype biomes surface on the lowlands.
150    // Deterministic + additive; the disabled path remains a verified no-op.
151    //
152    // E3-terrain Phase A (2026-07-01): flipped back to FALSE for the
153    // Minecraft-1.18 spline build. Mountains are now gated by the
154    // EROSION-driven `mountains_amplitude` spline (spline_types.rs
155    // climate_driven_spline_set); keeping this continentalness-multiplier
156    // modulation ON would double-gate mountains (appearing only where erosion
157    // is low AND continentalness high). Disabling it lets erosion alone drive
158    // the flat-vs-mountain REGIONS, with continentalness driving base elevation
159    // via its own spline.
160    false
161}
162fn default_continental_scale() -> f32 {
163    // Phase 1.6-F.2-T.B.1: raised from 0.0004 to 0.0012 (wavelength
164    // dropped ~2500 → ~830 world units). F.2-T.A diagnostic found that
165    // at scale 0.0004, seed 12345's continental field maxed at 0.669
166    // across the editor's ~2800-unit terrain extent (p95=0.631), with
167    // no samples > 0.7 — i.e. NO highland regions in visible terrain,
168    // breaking the F.2 core design intent of regional mountain clustering.
169    // Scale 0.0012 fits ~3.4 continental periods within the visible
170    // extent, ensuring both low-continental (lowland) and high-continental
171    // (highland) regions exist at every practical seed.
172    //
173    // Phase 1.6-F.4.B.2.F: scaled 0.0012 → 0.0003 for Target B world extent
174    // (radius 10 × 512 WU = 10752 WU). Preserves ~3-4 continental periods
175    // across the new extent. At the old 0.0012 = 830 WU wavelength, a
176    // radius-10 world would see ~13 periods — noise-like rather than
177    // regional clustering. New 0.0003 = ~3300 WU wavelength, matching
178    // plan §2.6 intent for regional highland/lowland clustering at the
179    // world's horizontal scale.
180    0.0003
181}
182fn default_continental_min() -> f32 {
183    // Phase 1.6-F.2-T.B.1: raised from 0.15 to 0.50. F.2-T.A diagnostic
184    // H1 measured detail_abs / mountain_effective ratio = 0.60 in
185    // lowlands — the intrinsically-spiky Billow detail layer became
186    // comparable to the continental-suppressed mountain layer, producing
187    // the bed-of-nails visible surface. A higher continental_min keeps
188    // more mountain character in lowlands, making detail's spikiness a
189    // smaller relative perturbation.
190    //
191    // F.2-T.B.1 initially chose 0.35, but the highland-Y-max regression
192    // test measured only 87.55 units (target ≥ 100) because even the
193    // highest continental_01 in the editor's terrain extent (0.874 per
194    // F.2-T.A) only yielded multiplier = 0.35 + 0.65×0.874 = 0.918, so
195    // highland peaks reached ~73 units of mountain layer. Raised to 0.50
196    // so the highland multiplier approaches 0.94 at cont_01=0.874, with
197    // detail-reduction (F.2-T.B.2) keeping H1 resolved (detail ratio in
198    // lowlands stays acceptable because detail_amplitude was halved
199    // alongside).
200    //
201    // E3-terrain.3 (2026-07-01): lowered 0.50 → 0.08. The 0.50 floor kept
202    // ~50% of the 480 mountain amplitude in every region, so enabling
203    // continental produced "smaller mountains everywhere" instead of the
204    // lowland↔highland CONTRAST the director wants. At 0.08, lowland regions
205    // (continental_01≈0.14) keep only ~20% mountain (near-flat, climate
206    // biomes surface) while highland regions (continental_01≈0.79) reach
207    // ~0.81× the full 480 → peaks ~500m so cold-climate SnowCap can form.
208    // Paired with base_elevation.amplitude 150→100 and detail 12.5→8 to keep
209    // the flattened lowlands from reading as bed-of-nails (the reason 0.50
210    // was originally chosen).
211    //
212    // E3-terrain.2: lowered 0.08 → 0.0 alongside the continental contrast
213    // curve (sample_height_with_params), so low-continental regions get ZERO
214    // mountain (pure base = flat/rolling grassland/rainforest plains) and only
215    // high-continental regions form mountains — the distinct plains-vs-mountains
216    // structure the director wants. detail.amplitude (8) is low enough that
217    // pure-base lowlands don't read as bed-of-nails.
218    0.0
219}

318/// Configuration for domain warping (noise-on-noise).
319///
320/// Domain warping offsets input coordinates with secondary noise fields
321/// before evaluating the primary noise. Multiple iterations create
322/// increasingly organic, swirled patterns reminiscent of geological
323/// formations, marble textures, and coastlines.
324///
325/// Reference: Inigo Quilez, "Domain Warping" (2002/2019).
326#[derive(Debug, Clone, Serialize, Deserialize)]
327pub struct DomainWarpConfig {
328    /// Number of warp iterations (1 = simple warp, 2+ = nested warps).
329    /// Each iteration feeds the result of the previous warp as input.
330    pub iterations: u32,
331    /// Scale of the warping noise (relative to the base noise scale).
332    pub warp_scale: f64,
333    /// Warp strength — how much the coordinates are displaced (world units).
334    pub warp_strength: f64,
335    /// Octaves for the warping noise.
336    pub warp_octaves: usize,
337}

363/// Domain-warped noise function.
364///
365/// Displaces input coordinates through one or more iterations of noise-on-noise,
366/// producing organic terrain features (swirled ridges, eroded coastlines, marble veins).
367///
368/// For N iterations:
369///   p₀ = input
370///   p₁ = p₀ + strength * warp_noise(p₀)
371///   p₂ = p₁ + strength * warp_noise(p₁)
372///   ...
373///   output = primary_noise(pₙ)
374struct DomainWarpedNoise {
375    /// Primary noise evaluated at the warped coordinates.
376    primary: Fbm<Perlin>,
377    /// Warp noise fields (one per axis: X, Z). Y stays at 0 for terrain.
378    warp_x: Fbm<Perlin>,
379    warp_z: Fbm<Perlin>,
380    /// How many times to apply warping.
381    iterations: u32,
382    /// How much the coordinates are displaced per iteration.
383    warp_strength: f64,
384}
385
386impl DomainWarpedNoise {
387    fn new(layer: &NoiseLayer, seed: u64) -> Self {
388        let dw = &layer.domain_warp;
389
390        let primary = Fbm::<Perlin>::new(seed as u32)
391            .set_octaves(layer.octaves)
392            .set_persistence(layer.persistence)
393            .set_lacunarity(layer.lacunarity);
394
395        // Use different seeds for each warp axis to decorrelate them.
396        let warp_x = Fbm::<Perlin>::new(seed as u32 + 100)
397            .set_octaves(dw.warp_octaves)
398            .set_persistence(0.5)
399            .set_lacunarity(2.0);
400
401        let warp_z = Fbm::<Perlin>::new(seed as u32 + 200)
402            .set_octaves(dw.warp_octaves)
403            .set_persistence(0.5)
404            .set_lacunarity(2.0);
405
406        Self {
407            primary,
408            warp_x,
409            warp_z,
410            iterations: dw.iterations.max(1),
411            warp_strength: dw.warp_strength,
412        }
413    }
414}

416impl DomainWarpedNoise {
417    /// Phase 1.6-F.2-T-4: apply only the coordinate-warping step, returning
418    /// the warped `(x, z)` pair without sampling the primary. Used by
419    /// `TerrainNoise::sample_height` when the base layer uses derivative-
420    /// weighted fBm — the warp still happens, but the primary evaluation is
421    /// replaced by `fbm_derivative_weighted_2d`.
422    fn warp_coords(&self, x: f64, y: f64, z: f64) -> (f64, f64) {
423        let mut wx = x;
424        let mut wz = z;
425        for _ in 0..self.iterations {
426            let dx = self.warp_x.get([wx, y, wz]) * self.warp_strength;
427            let dz = self.warp_z.get([wx, y, wz]) * self.warp_strength;
428            wx += dx;
429            wz += dz;
430        }
431        (wx, wz)
432    }
433}
434
435impl NoiseFn<f64, 3> for DomainWarpedNoise {
436    fn get(&self, point: [f64; 3]) -> f64 {
437        let (wx, wz) = self.warp_coords(point[0], point[1], point[2]);
438        self.primary.get([wx, point[1], wz])
439    }
440}

474impl TerrainNoise {
475    /// Create a new terrain noise generator
476    pub fn new(config: &NoiseConfig, seed: u64) -> Self {
477        let base_elevation = Self::create_noise_fn(&config.base_elevation, seed);
478        let mountains = Self::create_noise_fn(&config.mountains, seed + 1);
479        let detail = Self::create_noise_fn(&config.detail, seed + 2);
480
481        // 3D ridged-multi noise for cave carving.
482        // Ridged noise produces narrow, connected ridges — when thresholded,
483        // these become tunnel-like cave networks.
484        let cave_noise: Box<dyn NoiseFn<f64, 3> + Send + Sync> = Box::new(
485            RidgedMulti::<Perlin>::new(seed as u32 + 42)
486                .set_octaves(4)
487                .set_persistence(0.5)
488                .set_lacunarity(2.0),
489        );
490
491        // Phase 1.6-F.2 §2.6: continental-scale plain Perlin. Seeded
492        // deterministically from (world_seed + continental_seed_offset) so
493        // the field is a pure function of (world_seed, world_x, world_z).
494        let continental_seed = seed.wrapping_add(config.continental_seed_offset as u64) as u32;
495        let continental = Perlin::new(continental_seed);
496
497        // Phase 1.6-F.2-T-4: if the base layer uses DomainWarped noise AND
498        // derivative-weighted fBm is enabled, we need a dedicated
499        // DomainWarpedNoise instance to re-use its warp-coords helper. The
500        // warp-coords path is decoupled from the primary Fbm sampling — we
501        // warp coordinates, then feed the warped coords to
502        // fbm_derivative_weighted_2d as the primary evaluation.
503        let base_dw_for_coords =
504            if matches!(config.base_elevation.noise_type, NoiseType::DomainWarped)
505                && config.base_derivative_weighted
506            {
507                Some(DomainWarpedNoise::new(&config.base_elevation, seed))
508            } else {
509                None
510            };

554    /// Generate a heightmap for a terrain chunk
555    pub fn generate_heightmap(
556        &self,
557        chunk_id: ChunkId,
558        chunk_size: f32,
559        resolution: u32,
560    ) -> anyhow::Result<Heightmap> {
561        let heightmap_config = HeightmapConfig {
562            resolution,
563            ..Default::default()
564        };
565        let mut heightmap = Heightmap::new(heightmap_config)?;
566
567        let world_origin = chunk_id.to_world_pos(chunk_size);
568        let step = chunk_size / (resolution - 1) as f32;
569
570        for z in 0..resolution {
571            for x in 0..resolution {
572                let world_x = world_origin.x + x as f32 * step;
573                let world_z = world_origin.z + z as f32 * step;
574
575                let height = self.sample_height(world_x as f64, world_z as f64);
576                heightmap.set_height(x, z, height);
577            }
578        }
579
580        Ok(heightmap)
581    }

591    /// [`BootstrapParams`] (from an archetype's `BootstrapSplineSet`) instead
592    /// of reading the four bootstrap parameters from `self.config`. Composes
593    /// with the per-biome `mountain_amplitude_multiplier` from D.3b's
594    /// `BiomeParameters` blending.
595    ///
596    /// Replaced reads (vs [`Self::sample_height_with_mountain_amplitude`]):
597    /// - `self.config.base_elevation.amplitude` → `params.base_elevation_amplitude`
598    /// - `self.config.mountains.amplitude` → `params.mountains_amplitude`
599    /// - `self.config.mountains.scale` → `params.mountains_scale`
600    /// - `self.config.continental_scale` → `params.continental_scale`
601    ///
602    /// All other `self.config.*` reads (octaves, persistence, lacunarity,
603    /// noise type, base_elevation.scale, detail.*, continental_min,
604    /// continental_enabled, runevision config, base_derivative_weighted,
605    /// base_octave_weights) are unchanged.
606    ///
607    /// **Operation order discipline (F.3 prompt §3)**: this method's
608    /// arithmetic mirrors `sample_height_with_mountain_amplitude` exactly,
609    /// substituting only the four `params.*` reads. Any deviation in
610    /// operation order would produce f32 drift relative to the legacy path
611    /// and break the F.4.B.3.D.5-fix Path B byte-identical regression
612    /// contract.
613    ///
614    /// **Architectural deviation from F.3 prompt §2.1** (logged in
615    /// `REGIONAL_ARCHETYPE_VARIATION_CAMPAIGN.md` §10 F.3 entry): the F.3
616    /// prompt's signature was `sample_height_with_params(&BootstrapParams,
617    /// x: f32, z: f32) -> f32` (3 args). Actual signature is 4 args
618    /// (adds `mountain_amplitude_multiplier: f32`) because D.3b's
619    /// `apply_per_biome_modulation_to_halo` already passes a per-biome
620    /// multiplier to the legacy `sample_height_with_mountain_amplitude`;
621    /// F.3's wiring needs to compose with that multiplier rather than
622    /// replace it. Per-biome amplitude (D.3b) and per-archetype amplitude
623    /// (F.3) are architecturally orthogonal layers that multiply.
624    ///
625    /// `mountain_amplitude_multiplier`:
626    /// - `1.0` = baseline (no per-biome scaling on top of the archetype
627    ///   spline output).
628    /// - `< 1.0` / `> 1.0` = damped or boosted per-biome contribution.
629    ///
630    /// At the F.2 catalog default (single-control-point splines at the
631    /// F.4.B.3.D.5-fix baseline) and `mountain_amplitude_multiplier = 1.0`,
632    /// this method produces byte-identical output to `sample_height_with_mountain_amplitude(x, z, 1.0)`.
633    pub fn sample_height_with_params(
634        &self,
635        params: &crate::spline_types::BootstrapParams,
636        x: f64,
637        z: f64,
638        mountain_amplitude_multiplier: f32,
639    ) -> f32 {
640        // Composition order (mirrors `sample_height_with_mountain_amplitude`
641        // exactly; only the four `params.*` reads differ from the legacy
642        // path). See that method's doc-comment for the original ordering
643        // commentary.
644        // E3-terrain Phase A.2: start from the per-archetype ground-level floor
645        // so FLAT terrain sits above sea level (the signed base-elevation Fbm
646        // adds/subtracts around this floor). D5FIX baseline floor is 0.0, so this
647        // is a no-op on the legacy-baseline path. See
648        // `BootstrapParams::base_elevation_floor`.
649        let mut height = params.base_elevation_floor;
650        let mut base_gradient = (0.0f32, 0.0f32);
651
652        // Base elevation. Replaces `self.config.base_elevation.amplitude`
653        // with `params.base_elevation_amplitude`; all other base reads
654        // (scale, octaves, persistence, lacunarity, noise type) come from
655        // `self.config`.
656        if self.config.base_elevation.enabled {
657            let noise_val = if self.config.base_derivative_weighted {
658                let (sx, sz) = (
659                    x * self.config.base_elevation.scale,
660                    z * self.config.base_elevation.scale,
661                );
662                let (sx, sz) = if let Some(dw) = &self.base_dw_for_coords {
663                    dw.warp_coords(sx, 0.0, sz)
664                } else {
665                    (sx, sz)
666                };
667                let (val, grad) = crate::perlin_gradient::fbm_derivative_weighted_with_gradient_2d(
668                    self.base_dw_seed,
669                    sx as f32,
670                    sz as f32,
671                    self.config.base_elevation.octaves as u32,
672                    self.config.base_elevation.persistence as f32,
673                    self.config.base_elevation.lacunarity as f32,
674                    self.config.base_octave_weights.as_deref(),
675                );
676                base_gradient = grad;
677                val
678            } else {
679                self.base_elevation.get([
680                    x * self.config.base_elevation.scale,
681                    0.0,
682                    z * self.config.base_elevation.scale,
683                ]) as f32
684            };
685            // ED-3: the editor's amplitude lever — a scale on the
686            // spline-derived amplitude, default 1.0 (exact identity).
687            height +=
688                noise_val * (params.base_elevation_amplitude * self.config.base_amplitude_scale);
689        }
690
691        // Mountains — replaces `self.config.mountains.amplitude` with
692        // `params.mountains_amplitude`, `self.config.mountains.scale` with
693        // `params.mountains_scale`, `self.config.continental_scale` with
694        // `params.continental_scale`. continental_enabled, continental_min,
695        // and the per-biome multiplier composition are unchanged.
696        if self.config.mountains.enabled {
697            let noise_val =
698                self.mountains
699                    .get([x * params.mountains_scale, 0.0, z * params.mountains_scale])
700                    as f32;
701            let mountain_height_raw = noise_val.abs() * params.mountains_amplitude;
702
703            let mountain_height = if self.config.continental_enabled {
704                let continental_raw = self.continental.get([
705                    x * params.continental_scale as f64,
706                    0.0,
707                    z * params.continental_scale as f64,
708                ]) as f32;
709                let continental_01 = ((continental_raw + 1.0) * 0.5).clamp(0.0, 1.0);
710                // E3-terrain.2: contrast curve for DISTINCT regions. The raw
711                // continental field only spans ~[0.14, 0.79] at editor scale,
712                // so a linear multiplier left mountains present everywhere
713                // ("repetitive mountain scape"). A smoothstep pushes
714                // low-continental areas toward 0 (genuine flat/rolling lowlands
715                // where mountains are OFF and grassland/rainforest biomes live)
716                // and high-continental areas toward 1 (concentrated mountain
717                // ranges) — yielding distinct plains-vs-mountain regions.
718                let t = ((continental_01 - 0.30) / (0.72 - 0.30)).clamp(0.0, 1.0);
719                let continental_contrasted = t * t * (3.0 - 2.0 * t);
720                let multiplier = self.config.continental_min
721                    + (1.0 - self.config.continental_min) * continental_contrasted;
722                mountain_height_raw * multiplier
723            } else {
724                mountain_height_raw
725            };
726            height += mountain_height * mountain_amplitude_multiplier;
727        }
728
729        // Detail (unchanged from legacy path; F.3 doesn't expose detail
730        // parameters in BootstrapParams).
731        if self.config.detail.enabled {
732            let noise_val = self.detail.get([
733                x * self.config.detail.scale,
734                0.0,
735                z * self.config.detail.scale,
736            ]) as f32;
737            height += noise_val * self.config.detail.amplitude;
738        }
739
740        // Runevision filter (unchanged from legacy path).
741        if let Some(rv_config) = &self.config.runevision {
742            if self.config.base_derivative_weighted {
743                height = crate::runevision_erosion::apply_runevision_filter(
744                    height,
745                    base_gradient,
746                    x,
747                    z,
748                    self.base_dw_seed as u64,
749                    rv_config,
750                );
751            }
752        }
753
754        height.max(0.0)
755    }

757    /// Phase 1.6-F.4.B.3.D.3b: sample height at a world position with a
758    /// per-vertex multiplier applied to the mountain layer contribution.
759    ///
760    /// `mountain_amplitude_multiplier`:
761    /// - `1.0` = baseline (legacy `sample_height` behavior, no per-biome
762    ///   scaling). All callers prior to D.3b use this.
763    /// - `< 1.0` = damped mountain contribution (e.g., grassland biomes).
764    /// - `> 1.0` = boosted mountain contribution (e.g., alpine biomes).
765    ///
766    /// Multiplier is applied AFTER continental modulation but BEFORE the
767    /// runevision filter. This means continental clustering still shapes
768    /// regional highland/lowland zones, then per-biome amplitude refines
769    /// each region's local character.
770    ///
771    /// New per-vertex per-biome amplitude path. `WorldGenerator::generate_chunk_with_climate`
772    /// uses this method to apply `BiomeParameters::mountains_amplitude` from
773    /// the per-vertex `BiomeId` lookup. Replaces the legacy whole-world
774    /// per-`BiomeNoisePreset` amplitude pattern.
775    pub fn sample_height_with_mountain_amplitude(
776        &self,
777        x: f64,
778        z: f64,
779        mountain_amplitude_multiplier: f32,
780    ) -> f32 {
781        // Composition order (documented per F.4.B.3.C plan §1.C, extended
782        // for F.4.B.3.D.3 per-biome amplitude):
783        //   1. Base layer fBm with derivative-weighted attenuation (F.2-T-4)
784        //   2. Mountain layer fBm + continental modulation (F.2 + F.2.6)
785        //      → multiplied by per-biome `mountain_amplitude_multiplier` (D.3b)
786        //   3. Detail layer Billow (F.2)
787        //   4. Sum of layers
788        //   5. → runevision erosion filter adds gradient-aligned gully detail
789        //      using base-layer gradient as a proxy for combined-output gradient
790        //      (mountain layer uses opaque RidgedMulti without analytical
791        //      gradient access; F.4.B.3.C §1.B Position B). Active only when
792        //      `config.runevision.is_some()` AND `base_derivative_weighted`
793        //      is also true.
794        //   6. Final height clamped to non-negative
795        //
796        // F.3 particle erosion runs AFTER this function returns
797        // (in `apply_preset_at_world_offset`). The runevision-filtered terrain
798        // is its starting state.
799        let mut height = 0.0f32;
800        // F.4.B.3.C: capture base-layer gradient when derivative-weighted fBm
801        // is active. Used downstream by runevision filter as the slope/flow
802        // direction proxy for the combined output. Stays (0,0) when base
803        // derivative-weighted path is disabled (filter then becomes a no-op
804        // because runevision short-circuits on near-zero gradient).
805        let mut base_gradient = (0.0f32, 0.0f32);
806
807        // Base elevation.
808        //
809        // Phase 1.6-F.2-T-4: when `config.base_derivative_weighted` is true,
810        // replace the primary Fbm evaluation with derivative-weighted fBm
811        // (Quilez morenoise). If the base layer also uses DomainWarped noise,
812        // apply the coordinate warping first (reusing the warp_coords helper)
813        // and then call fbm_derivative_weighted_2d at the warped coords.
814        if self.config.base_elevation.enabled {
815            let noise_val = if self.config.base_derivative_weighted {
816                let (sx, sz) = (
817                    x * self.config.base_elevation.scale,
818                    z * self.config.base_elevation.scale,
819                );
820                // If base is DomainWarped, warp the scaled coords before fBm.
821                let (sx, sz) = if let Some(dw) = &self.base_dw_for_coords {
822                    dw.warp_coords(sx, 0.0, sz)
823                } else {
824                    (sx, sz)
825                };
826                // F.4.B.3.C: use the gradient-returning variant. Gradient is
827                // already accumulated internally by morenoise for attenuation;
828                // exposing it as output is zero-cost.
829                let (val, grad) = crate::perlin_gradient::fbm_derivative_weighted_with_gradient_2d(
830                    self.base_dw_seed,
831                    sx as f32,
832                    sz as f32,
833                    self.config.base_elevation.octaves as u32,
834                    self.config.base_elevation.persistence as f32,
835                    self.config.base_elevation.lacunarity as f32,
836                    self.config.base_octave_weights.as_deref(),
837                );
838                base_gradient = grad;
839                val
840            } else {
841                self.base_elevation.get([
842                    x * self.config.base_elevation.scale,
843                    0.0,
844                    z * self.config.base_elevation.scale,
845                ]) as f32
846            };
847            height += noise_val * self.config.base_elevation.amplitude;
848        }
849
850        // Mountains — with optional continental-scale amplitude modulation.
851        // Phase 1.6-F.2 §2.6: when continental_enabled, the mountain layer's
852        // contribution is multiplied by mix(continental_min, 1.0, continental_01),
853        // where continental_01 is the continental noise at (x, z) mapped from
854        // [-1, 1] to [0, 1]. This produces regional clustering of mountain
855        // zones vs. lowland zones — mountain-country regions retain full
856        // amplitude, lowland regions retain continental_min (default 0.15) of
857        // the full amplitude.
858        if self.config.mountains.enabled {
859            let noise_val = self.mountains.get([
860                x * self.config.mountains.scale,
861                0.0,
862                z * self.config.mountains.scale,
863            ]) as f32;
864            // Use absolute value for ridged effect
865            let mountain_height_raw = noise_val.abs() * self.config.mountains.amplitude;
866
867            let mountain_height = if self.config.continental_enabled {
868                let continental_raw = self.continental.get([
869                    x * self.config.continental_scale as f64,
870                    0.0,
871                    z * self.config.continental_scale as f64,
872                ]) as f32;
873                // Perlin output is approximately [-1, 1]; map to [0, 1].
874                let continental_01 = ((continental_raw + 1.0) * 0.5).clamp(0.0, 1.0);
875                let multiplier = self.config.continental_min
876                    + (1.0 - self.config.continental_min) * continental_01;
877                mountain_height_raw * multiplier
878            } else {
879                mountain_height_raw
880            };
881            // Phase 1.6-F.4.B.3.D.3b: per-biome mountain amplitude multiplier.
882            // Applied AFTER continental modulation, so continental clustering
883            // still shapes regional highland/lowland zones, then per-biome
884            // amplitude refines each region's local character.
885            height += mountain_height * mountain_amplitude_multiplier;
886        }
887
888        // Detail
889        if self.config.detail.enabled {
890            let noise_val = self.detail.get([
891                x * self.config.detail.scale,
892                0.0,
893                z * self.config.detail.scale,
894            ]) as f32;
895            height += noise_val * self.config.detail.amplitude;
896        }
897
898        // Phase 1.6-F.4.B.3.C: runevision erosion filter (Skovbo Johansen).
899        // Position B per F.4.B.3.C plan §1.B: AFTER continental modulation,
900        // BEFORE non-negative clamp. Lowland gully contributions are
901        // naturally smaller because continental modulation has already
902        // reduced mountain amplitude there — geologically correct.
903        // Filter is a no-op when:
904        //   - config.runevision is None (preset opt-out), OR
905        //   - base_derivative_weighted is false (no analytical gradient
906        //     available — mountain layer's RidgedMulti is opaque), OR
907        //   - gradient magnitude is near zero (flat terrain), OR
908        //   - height is below valley_altitude (altitude fade = 0).
909        if let Some(rv_config) = &self.config.runevision {
910            if self.config.base_derivative_weighted {
911                height = crate::runevision_erosion::apply_runevision_filter(
912                    height,
913                    base_gradient,
914                    x,
915                    z,
916                    self.base_dw_seed as u64,
917                    rv_config,
918                );
919            }
920        }
921
922        // Ensure non-negative heights
923        height.max(0.0)
924    }

1005    /// Sample 3D density for isosurface extraction (caves, overhangs).
1006    ///
1007    /// Returns a signed density value:
1008    /// - **Positive** = solid terrain (inside surface)
1009    /// - **Negative** = air / void (outside surface)
1010    ///
1011    /// The density combines:
1012    /// 1. A height-relative base: `surface_height - y` (positive underground)
1013    /// 2. 3D ridged-multi noise subtracted as a cave mask, producing
1014    ///    tunnel-like voids when the noise exceeds `cave_threshold`
1015    ///
1016    /// Cave networks form where ridged noise creates narrow high-value ridges
1017    /// in 3D space. The `cave_strength` parameter controls carving intensity.
1018    pub fn sample_density(&self, x: f64, y: f64, z: f64) -> f32 {
1019        // Base density: above terrain surface = negative (air), below = positive (solid)
1020        let surface_height = self.sample_height(x, z) as f64;
1021        let base_density = surface_height - y;
1022
1023        // 3D cave noise at cave_frequency scale
1024        let freq = self.config.cave_frequency;
1025        let cave_sample = self.cave_noise.get([x * freq, y * freq, z * freq]);
1026
1027        // Ridged-multi outputs roughly [−1, 1]. We map to [0, 1] and threshold.
1028        let cave_val = (cave_sample * 0.5 + 0.5).clamp(0.0, 1.0);
1029
1030        // Carve caves where noise exceeds threshold (narrow ridged peaks = tunnels)
1031        let cave_mask = if cave_val > self.config.cave_threshold {
1032            // Smooth falloff above threshold
1033            let excess = (cave_val - self.config.cave_threshold)
1034                / (1.0 - self.config.cave_threshold + 1e-10);
1035            excess * excess * self.config.cave_strength
1036        } else {
1037            0.0
1038        };
1039
1040        // Depth attenuation: caves weaken near the surface to prevent sky holes,
1041        // and taper off at extreme depth to keep a solid floor.
1042        let depth_below_surface = (surface_height - y).max(0.0);
1043        let surface_guard = (depth_below_surface / 10.0).clamp(0.0, 1.0); // ramp over 10 units
1044        let deep_guard = 1.0 - ((depth_below_surface - 200.0) / 50.0).clamp(0.0, 1.0); // taper after 200
1045        let depth_factor = surface_guard * deep_guard;
1046
1047        // Final density: base minus cave carving
1048        let carve_strength = 80.0; // world-unit carving radius
1049        let density = base_density - cave_mask * carve_strength * depth_factor;
1050
1051        density as f32
1052    }

1110    /// Normalize a height array to 0-1 range
1111    pub fn normalize_heights(heights: &mut [f32]) {
1112        if heights.is_empty() {
1113            return;
1114        }
1115
1116        let min_height = heights.iter().copied().fold(f32::INFINITY, f32::min);
1117        let max_height = heights.iter().copied().fold(f32::NEG_INFINITY, f32::max);
1118        let range = max_height - min_height;
1119
1120        if range > 0.0 {
1121            for height in heights.iter_mut() {
1122                *height = (*height - min_height) / range;
1123            }
1124        }
1125    }

1136    pub fn create_island_mask(size: u32, center_x: f32, center_z: f32, radius: f32) -> Vec<f32> {
1137        let mut mask = Vec::with_capacity((size * size) as usize);
1138
1139        for z in 0..size {
1140            for x in 0..size {
1141                let dx = x as f32 - center_x;
1142                let dz = z as f32 - center_z;
1143                let distance = (dx * dx + dz * dz).sqrt();
1144
1145                let falloff = if distance < radius {
1146                    1.0 - (distance / radius).powf(2.0)
1147                } else {
1148                    0.0
1149                };
1150
1151                mask.push(falloff.clamp(0.0, 1.0));
1152            }
1153        }

1463        let mut total = 0.0f32;

1465        for i in 1..grid_dim - 1 {
1466            for j in 1..grid_dim - 1 {
1467                let center = heights[i * grid_dim + j];
1468                let neighbors = heights[(i - 1) * grid_dim + j]
1469                    + heights[(i + 1) * grid_dim + j]
1470                    + heights[i * grid_dim + j - 1]
1471                    + heights[i * grid_dim + j + 1];
1472                total += (center - neighbors / 4.0).abs();
1473                count += 1;
1474            }
1475        }

1730    /// `BootstrapParams.mountains_scale: f32`, which produced ~60-ulp

1732    /// exact representation. The drift propagated through erosion (per

1734    /// divergence at chunk shared edges, breaking phase-2 continuity
1735    /// (80 WU threshold). F.3.B retrofit changed `BootstrapParams.mountains_scale`

1743    /// If a future change introduces drift, this test surfaces the
1744    /// regression immediately.

1747        let config = NoiseConfig::default();
