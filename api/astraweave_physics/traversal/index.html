Module traversal

Source
Expand description

Tick-based traversal sim. The Aravath motor and the replay gate both call it. Tick-based traversal.

One tick is [TICK_DT] (60 Hz). The sim owns displacement. Callers pass a [ProbeFrame] from Rapier, or a flat plane for the replay gate. Slope and jump roots go through [crate::detmath] (libm). Random draws, when a later phase needs them, use astraweave_core::SimRng and SIM_SYSTEM_TRAVERSAL. This module does not read the clock.
