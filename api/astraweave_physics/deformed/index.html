Module deformed

Expand description

Traversal against terrain that can be dug, fractured, or collapsed.

Samples are a fixed 3×3 of column heights. deformed_step does not allocate. Geometry notices and climb flags come from astraweave-destruction (PR #243): GeometryNotice and allows_climb.
