Column ring deformation. Command types, Fixed64, and VoxelDag are the ones on main (astraweave-destruction, astraweave-math). This module keeps the ring’s occupancy replay, which the destruction crate does not export: its Terrain slot set is four chunks, and the loaded ring is the slot set.
