Pre-sized column ring. The loaded set is the destruction slot set.

around fills a stack array, sorts it in place by (x, z), and merge-joins it with the residents. Slot storage, the command log, and the free list are allocated in new. The tick does not allocate. At most MAX_REMESHES_PER_TICK chunks rebuild their voxel DAG per call.
