Module gpu_profiler

Source
Expand description

GPU timestamp profiler for per-pass performance analysis.

Wraps wgpu’s timestamp query mechanism to automatically capture timing for each render/compute pass. Results are read back asynchronously and exposed as per-pass millisecond durations.

Requires Features::TIMESTAMP_QUERY on the device.
