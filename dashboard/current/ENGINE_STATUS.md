## Determinism

Determinism is non-negotiable. `.github/workflows/determinism-replay.yml` runs on every pull request and on push to `main`, with no path filter. Each OS pins a baseline CPU (`target-cpu=x86-64` on x86_64; Apple Silicon stays on the default aarch64 baseline). `cargo test` in this workflow is not retried.

The compare job requires these nineteen cases to be present and byte-identical across Linux, Windows, and macOS:

`planner_pure`, `perception_world`, `gameplay_rng`, `fixed64`, `combat_resolve`, `destruction`, `gameplay_qa_aravath_slice`, `nav_reroute`, `causal_bridge`, `scripted_system`, `weaving`, `traversal`, `traversal_deformed`, `worldgen_columns`, `deformed_chunk`, `local_sim`, `greybox_checkpoint`, `quest_ticks`, `persist_replay`.

`worldgen_columns` and `deformed_chunk` are written into `target/replay-hash.json` by `cargo test -p astraweave-terrain --test worldgen_hash` before the merge step. They do not have a separate artifact file. `local_sim` is written to `target/replay-hash-localsim.json` by `cargo test -p astraweave-localsim --test replay_hash`. `greybox_checkpoint` is `cargo test -p aravath_runtime --test checkpoint_replay` (`replay-hash-greybox.json`): the save id and timestamp come from the sim tick, and the digest covers the restored fight. `quest_ticks` is `cargo test -p astraweave-quests --test quest_tick_replay` (`replay-hash-quests.json`): quest stamps are sim ticks. `persist_replay` is `cargo test -p astraweave-persistence-ecs --test persist_replay` (`replay-hash-persist.json`): replay applies due events in order, and autosave ids come from `CSimClock`. The merge step concatenates those files.

The ECS schedule itself is single-threaded per tick, in this order: `PRE_SIMULATION`, `PERCEPTION`, `SIMULATION`, `SYNC`, `AI_PLANNING`, `PHYSICS`, `POST_SIMULATION`, `PRESENTATION`. `ParallelSchedule` was removed on 2026-04-18 ([audit](../audits/parallel_schedule_removal_2026-04-18.md)). Rayon, tokio, and GPU compute live in subsystems, not inside the tick schedule.

## How the loop works

```text
Perception → local model proposes → plan → deterministic validation → simulation
```

1. **Perception.** Agents read a `WorldSnapshot`.
2. **Proposal.** A local LLM, a utility score, or a behavior tree proposes a plan. The deterministic tick does not call `AIArbiter` or `GoapPlanner` (#331). `gravity.rs` was deleted in #330.
3. **Validation.** The tool sandbox and the sim accept or reject the plan.
4. **Action.** Accepted steps run as deterministic ECS commands.

`hello_companion` exposes seven modes: Classical, Behavior Tree, Utility, LLM, Hybrid, Ensemble, and Arbiter. Behavior Tree, Utility, and Ensemble need `--features llm`. LLM and Hybrid need `--features ollama`. Arbiter needs `--features llm_orchestrator`. A default `cargo run -p hello_companion` does not enable all seven.

The 12,700-agent figure is a CPU capacity estimate for a mid-complexity AI loop on an i5-10300H with the platform allocator, measured 2026-06-27. It is not a full-frame GPU result. See [CLAIMS_REGISTRY.md](../campaigns/doc-truth/CLAIMS_REGISTRY.md#agents-capacity-60fps) and the [benchmark hardware note](../masters/MASTER_BENCHMARK_REPORT.md#benchmark-hardware).

## Build, test, and docs gates

```bash
cargo check -p <crate>
cargo test -p <crate>
cargo fmt --all
cargo clippy -p <crate> --all-features -- -D warnings
cargo run -p aw_doc_lint -- --mode warn
cargo run -p aw_trace_sync -- --check
```

Pull-request Rust work is tiered. The required replay check is `determinism-replay / compare`. Docs-only diffs skip the workspace compile; they still run the replay hashes. The full job list is [CI_ARCHITECTURE.md](CI_ARCHITECTURE.md). #217 and #327 are on `main`. #326 is closed.

`aw_doc_lint` reads the closed vocabulary in [CLOSED_VOCABULARY_LINT.md](../campaigns/doc-truth/CLOSED_VOCABULARY_LINT.md). The front door checks this page, after a closed HTML comment is removed, for every required replay case and for the frame phrases, including the earlier capture and the later median frame sample. `aw_doc_lint` looks for `3.117 ms` and `3.688 ms` as their own tokens on a sentence with whole-word `median` or `measured`, or whole-word `sample` with whole-word `is` or `was`, and it looks for the budget phrase as its own token so `111 ms` does not match. Whole-word `not`, `no`, `none`, `nobody`, `nothing`, `never`, `cannot`, `neither`, or `nor`, or an `n't` contraction, keeps that sentence off the set, including the budget phrase and the two prose phrases. The apostrophe may be ASCII, U+2018, U+2019, U+02BC, U+FF07, or a character reference that decodes to one of those. Status text is the pulldown-cmark render, with footnotes on. Code stays as that parser emitted it. A numeric character reference in text is decoded, including any run of leading zeros. A named reference in markdown text still ends in a semicolon, and a second pass does not run. Raw HTML and alt text decode a numeric character reference with an optional semicolon. 0 becomes U+FFFD. The range 0x80 through 0x9F uses the Windows-1252 row, so 0x92 and 146 are U+2019 and 0x85 is U+2026. Markdown text still requires that semicolon on a numeric reference, and a markdown numeric reference in that range is U+FFFD. Raw HTML and alt text also accept an HTML5 legacy name with no semicolon. A defined footnote reference writes a superscript digit. A referenced footnote definition is scanned. An unreferenced one is omitted. It folds U+FF01–U+FF5E into ASCII, and drops non-whitespace controls, the Cf and Mn characters `unicode_categories` 0.1.1 classifies, the Unicode 15 Cf and Mn gaps that crate misses, and U+115F, U+1160, U+3164, and U+FFA0. U+1734 stays. `unmeasured`, `No capture`, and `Nobody measured` do not count, and naming a capture is not a measurement. An unclosed `<!--` hides through the end of its block, blank lines included. `<!-->` and `<!--->` close the comment. A comment inside a code span or a fence stays text. A `script` or `style` body stays, because the rendered page shows it. Link labels join the surrounding letters. A link reference definition is omitted. An autolink keeps its URL. A `br` tag inserts a break. `CC0`, `GTX 1660 Ti`, and `Aravath` have to sit on a sentence that is not negated. A sentence that only names the check does not count. It checks the root README for the in-progress list. That heading is the rendered h2 whose folded text is exactly in progress, setext or ATX, and the section ends at the next rendered h2 that does not collapse to `in progress` or empty. Issue numbers in that section are read after the same fold, and those words are read from the folded render. It rejects a frame figure there, as that spec defines it. The frame scan uses that same render: it folds that fullwidth block, drops those characters, treats a backslash before a newline as a break, and applies the same comment, link, autolink, and break rules. It also rejects the retired game title in player-facing docs, including `docs/current/PROJECT_BRIEF.md`, from that render after the same fold. That check fails the process even while the vocabulary scan is still in warn mode.
