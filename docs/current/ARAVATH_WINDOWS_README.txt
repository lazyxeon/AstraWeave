Aravath demo

Keep this file, aravath_greybox.exe, and the assets folder together.
Double-click aravath_greybox.exe from this folder after extracting the whole zip.

If the window fails, read aravath.log and aravath_crash.log in this folder.
A message box should also appear.

Start without volumetric fog and light shafts:

  aravath_greybox.exe --no-volumetrics

The same switch can be written as volumetrics=off in aravath.cfg next to the exe.

Controls are listed in docs/current/ARAVATH_DEMO.md in the source tree.
WASD move, mouse looks, Shift sprints, Space jumps, Q rolls, F flies,
E digs, R places, 1-5 select the block, left mouse swings, right mouse blocks,
Tab locks on, F5 saves, F9 loads, Enter respawns, Escape quits.
