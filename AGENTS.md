# AGENTS.md

Constitution for every coding agent in this repository. Imperative. The owner is @lazyxeon.

## Precedence

1. The current user instruction, for that task only. Do not edit this file to match a one-off ask.
2. This file.
3. A nearer `AGENTS.md` or `AGENTS.override.md` on the path from the repo root to the file you are editing. Closer wins. There is no nested file today.
4. Tool mechanics only: `CLAUDE.md` (`@AGENTS.md` import and the trace table), `.cursor/rules/`, `.github/copilot-instructions.md`, `.coderabbit.yaml`. They do not override a rule here.
5. `docs/current/AGENT_FIELD_MANUAL.md` and `docs/current/COPILOT_FIELD_MANUAL.md` are the moved manuals. They are reference. This file wins.

`.cursorrules` is not used. Do not add one.

## Standing rules

- Determinism is 100%. Replay golden hashes never move without explicit owner sign-off. The required set is the `required` list in [`.github/workflows/determinism-replay.yml`](.github/workflows/determinism-replay.yml). No wall clock and no unseeded RNG on the sim path.
- One change per branch and pull request.
- Never ignore a failure. Fix it, or file a `deferred-failure` issue. Owner: `lazyxeon`. The issue states root cause, plan, and exit criteria.
- Do not add a `cargo audit` ignore or a `RUSTSEC` ignore in `deny.toml`, `.cargo/audit.toml`, or a workflow. Existing ignores are already tied to open issues in those files. Do not add another.
- Assets in the tree are CC0 only.
- Never put `Veilweaver` in player-facing text. A `veilweaver_` identifier and `projects/veilweaver` are not that text. The player-facing name is Aravath.
- Local LLMs only. They propose. The deterministic simulation validates and executes. Ollama stays on loopback unless the caller uses `allowing_remote`.
- The GPU frame budget is under 11 ms on a GTX 1660 Ti (min spec). Run it with `cargo run -p astraweave-render --release --features gpu-frame-budget --bin gpu_frame_budget`. Lavapipe time is not that budget.
- Never delete a working capability without a replacement.
- Agents do not merge. Report the green head SHA. The Admin Authorization ruleset blocks agent merges.
- Address the adversarial `cursor[bot]` review and CodeRabbit findings before asking for a merge.
- Never claim a result you did not measure. Label a measurement with its commit SHA and adapter.
- Keep the root README concise. Put new docs under `docs/` and new scripts under `scripts/`. Do not clutter the repo root.
- Be conservative with compute and usage. Prefer `cargo check -p <crate>` and `cargo test -p <crate>` over a workspace build.

## Commands that CI runs

Toolchain is Rust 1.89.0 (`rust-toolchain.toml`).

- Name gate, every pull request: `bash scripts/ci/player_facing_names.sh` ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)).
- Rust gate: `bash scripts/ci/run-gate.sh`. Docs-only diffs skip it. Otherwise `cargo fmt --all --check`, then clippy and `cargo check --locked` for the affected crates or the workspace ([`scripts/ci/run-gate.sh`](scripts/ci/run-gate.sh)).
- Tests: `bash scripts/ci/run-tests.sh` with `AW_CI_PROFILE=ci-pr` ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)).
- Replay: the `cargo test` lines in [`.github/workflows/determinism-replay.yml`](.github/workflows/determinism-replay.yml). No retry.
- Docs: `cargo run -p aw_doc_lint -- --mode warn` ([`.github/workflows/doc-truth-lint.yml`](.github/workflows/doc-truth-lint.yml)).
- Traces: `cargo run -p aw_trace_sync -- --check` ([`.github/workflows/trace-sync.yml`](.github/workflows/trace-sync.yml)). The generated table stays in `CLAUDE.md`. Do not hand-edit between the markers.
- Audit on the security workflow: `cargo deny check bans`, `sources`, `advisories`, `licenses`, then `cargo audit` ([`.github/workflows/security-audit.yml`](.github/workflows/security-audit.yml)).
- Frame capture, `workflow_dispatch` only, self-hosted GPU runner: `cargo run -p astraweave-render --release --features gpu-frame-budget --bin gpu_frame_budget -- --scene heavy --glb <path>` ([`.github/workflows/gpu-frame-budget.yml`](.github/workflows/gpu-frame-budget.yml)).
